Define absolute and relative error. When is relative error preferable?

Published: 27.02.2026

In News.

Absolute error is the difference between measured and true value: |x_measured - x_true|. Relative error is absolute error normalized by the true (or reference) value, usually in percent. Relative error is preferable when comparing accuracy across values with different scales.
